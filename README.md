# 智慧光 Wisdom Light

> **這是李慧萍的專案。**
> 2014 年 11 月 19 日，她在法鼓文理學院佛教學系碩士班通過論文計畫口考
> 《意義的生成初探—以江味農《金剛經講義》為例》，指導教授是**謝清俊**先生。
> 她把這個研究方向命名為「**智慧光**」。
>
> 計畫通過口考後沒有走完。近十二年後，這個專案重新啟航：
> 把她當年用手工做的三軌編碼（科判 K／經文 S／解釋 E），
> 做成可累積、可反查、可署名的資料與工具。

---

## 2014：她做到哪裡

- **範圍**：江味農《金剛經講義》對羅什譯《金剛經》前 331 字（含標點 412 字）所作的
  27,902 字解釋。
- **方法**：把科判（K）、經文（S）、解釋（E）三軌各自以**字數**編號，建立對應；
  再依理解程度把解釋細分成更小的意義單元（她稱「筆者科判」）。
- **發現**：意義的生成方式可歸為詞彙義、歷史情境、互為文本、同義關係等；
  例如江味農解「證信序」一段，與隋·吉藏《金剛般若疏》有明顯的文本參照關係。
- **工具**：與資訊專家合作，發展「電腦內容標誌」——
  讓人文學者不用學標記語言，也能在介面上標註自己對文本的理解。
  當年用的是中研院莊德明先生的「中文文獻處理系統」；
  她已在系統上做到科判與不同譯本經文的對照、科判／經文／注疏三者對照。

她的問題意識很簡單、也很難：

> **一句話的意義是怎麼生成的？誰說的、對哪一句說、憑什麼？**

## 2015：她連介面都畫好了

計畫通過口考後，她沒有停。2015 年 7 月，她畫了 47 頁的「智慧光小幫手」介面佈局與功能實例圖
（[design/智慧光介面佈局及功能實例圖(huiping2015.7.21).pptx](design/智慧光介面佈局及功能實例圖(huiping2015.7.21).pptx)）：
三種頁面佈局、右鍵小工具、下方科判與經文／註釋對讀，以及五大類功能。

| 類 | 她設計的功能 |
|---|---|
| 一、內容架構 | 昭明太子科判、江味農科判、**李慧萍增補科判**（三套並存） |
| 二、字詞釋義 | 科判—名相、名相、全經某類名相（例如找全經「如是」的解釋）、情境指涉 |
| 三、互為文本 | 譯本比對、內文引證、參校資料 |
| 四、情境指涉 | 文本內、跨文本 |
| 五、文義思考 | 點一個問題，出現對應的經文或解釋 |

她對這個系統的說明，原文照錄：

> 本系統是一個人機共建的系統，並提供讀者一個理解意義的工具。蓮花代表清淨無染。
> 閱讀小幫手取名為「智慧光」，是將佛陀慈悲與智慧的本懷，實踐在這個人機共建的系統上，
> 以眾人之智慧，提供理解的線索，幫助讀者理解佛法的意義。

這五類與今天的模型對應得很整齊，只有最後一類還沒有實作：

| 她 2015 的分類 | 今天的對應 |
|---|---|
| 內容架構（三套科判並存） | `anchor` ＋ 每版各自的 label（同一 anchor 可以有多套 vocabulary） |
| 字詞釋義 | 名相類 claim ＋ 術語表 |
| 互為文本 | `quotes`／`derives_from`／`parallel_of` 邊（譯本比對即六譯的 anchor_map） |
| 情境指涉 | 歷史情境（人、事、時、地、物）的 claim |
| **文義思考** | **尚未建模**：以「問題」為入口，反查對應的經文與解釋 |

## 我們認為它當年缺的三樣東西

不是想法不對，是基礎設施不夠。今天這三樣都可以補上：

| 當年缺 | 現在有 |
|---|---|
| **逆鏈**：反向索引——「這段話被誰引用過」 | 每個節點都能反查；注釋史變成一條可排序的時間線 |
| **字級座標**：精確到字的位址 | 大正藏、永樂藏、CBETA 都提供；其他古籍可以自己造（成本是算力，不是印刷） |
| **可署名、可累積的格式** | 每條主張帶「說者／記錄者／核對者」、版本、狀態、授權；機器草稿不得發布 |

## 這個專案在做什麼

1. **格式**：節點（原文、著作、段落）＋邊（引用、注釋、承襲、異說）＋錨點（語意歸屬與閱讀位置分開）。
2. **桌面 IDE**：讓不寫程式的專家也能建邊、反查、審核、編集注。
3. **分享**：成果要能單檔／單包帶走，對方不用安裝、不用伺服器。
