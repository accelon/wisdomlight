# 智慧光 Wisdom Light

> **一個幫你讀懂經典的閱讀小幫手。**
> 這份說明寫給佛學與文史研究者，不需要資訊背景；文末另有文件索引。

## 這是什麼

智慧光把一部經典的**經文、科判、註釋**放在同一個畫面上，並且讓每一句話都能反查：

- 打開一句經文，看得到歷代誰在這句話上說過什麼；
- 打開一條注，沿著線回到原文、版本、頁行，甚至第幾個字；
- 看到一條意見，知道是誰說的、誰記錄的、誰核對過。

它不重寫經典，也不替讀者下結論；它只是把材料排好，讓判斷有依據。

長遠來看，它會是三樣東西：一套開放的記錄格式、一個不用寫程式的桌面工具、一份可以帶走的成果包。

> 閱讀小幫手取名為「智慧光」，是將佛陀慈悲與智慧的本懷，實踐在這個人機共建的系統上，
> 以眾人之智慧，提供理解的線索，幫助讀者理解佛法的意義。
> ——李慧萍，2015

## 它從一個問題開始

2014 年 11 月，李慧萍在法鼓文理學院佛教學系通過論文計畫口考
《意義的生成初探—以江味農《金剛經講義》為例》，指導教授是謝清俊先生。她想問：

> **一句話的意義是怎麼生成的？誰說的、對哪一句說、憑什麼？**

當年她的做法是：把江味農對《金剛經》開頭 331 字（含標點 412 字）所作的 27,902 字解釋，
拆成科判（K）、經文（S）、解釋（E）三條線，各自以字數編號、互相對應；
再把自己進一步細分的小單元記下來。

計畫在口考之後沒有走完。十二年後，這個專案把她當年的手工，
做成可以累積、可以反查、可以署名的工具。

（[設計原圖](<design/智慧光介面佈局及功能實例圖(huiping2015.7.21).pptx>)）。這是她畫的「佈局 1」：

![智慧光小幫手版面：上方工具列，左邊是檢索結果、目錄與內容架構，右邊可同時開五份文本](<design/layout-1.png>)

- **三種版面**：可以同時看五份文本、兩份文本，或專心讀一份。
- **右鍵小工具**：選好要用的功能（字詞釋義、互為文本……），在經文上按右鍵就出現可點選的小視窗。
- **下方對讀**：捲動下方，一邊看科判，一邊對讀經文與註釋。

## 五種幫助

她把它們分成五類：

| 類 | 幫你做什麼 | 特色 |
|---|---|---|
| **內容架構** | 用科判把經文和註釋對起來 | 昭明太子、江味農、**李慧萍增補**三套科判並存，不互相取代 |
| **字詞釋義** | 查名相，看注家怎麼解、辭典怎麼說 | 也可以問「全經的『如是』出現在哪裡、各家怎麼解」 |
| **互為文本** | 譯本並排對讀；注家引了哪部經，一併帶出 | 六種漢譯＋梵文；江味農引《華嚴》，就把《華嚴》原文找出來 |
| **情境指涉** | 看一句話在上下文與跨文本中的關係 | 文本內的前後脈絡，以及跨文本的人、事、時、地 |
| **文義思考** | 從問題出發，找到對應的經文或解釋 | 這一類她畫了圖，但**還沒實作** |

## 三個原則（白話版）

1. **原文不動，意見掛上去。** 經文與版本是證據，凍結不改；後人的解釋是一條一條掛在經文上的意見，
   可以署名、可以修訂。編者的功勞在「選哪些、怎麼排、按語怎麼寫」。
2. **每句話都要能反查。** 除了「這段話是什麼意思」，還要能問「誰引用過這段話」。
   《金剛經》開頭一句「如是我聞」，現在就掛著八位前人作者、十條意見，跨一千五百年。
3. **人與機器分得出來。** 機器可以起草白話、摘要、比對、建議，但**發布一定要有人簽核**；
   純機器文字不會成為「已發布」。

## 目前做到哪裡

以《金剛經》為樣本，前三分已完成：

- 六種漢譯（羅什、菩提流支、真諦、笈多、玄奘、義淨）＋梵本，逐段對照。
- 注疏：吉藏《金剛般若疏》、江味農《金剛經講義》、朱棣《金剛經集注》節錄。
- 13 條意見：8 條前人（吉藏、江味農、王日休、李文會、傅大士、僧肇、六祖、僧若訥）＋5 條整理者。
- 從朱棣集注剝出六家，並認出二層引文（李文會文中引傅大士偈）。
- 江味農《講義》全文已入庫：36.5 萬字、364 節、501 頁碼。

一段經文如何長出八人反查，寫在 [samples/jingang/](samples/jingang/README.md)。

## 還沒做

- **文義思考**：從問題找經文的入口，還沒有設計。
- **介面**：2015 年畫的介面還沒做成軟體；目前有的是資料格式、樣本與工具規格。
- **其餘 29 分**：《金剛經》的對照表只做了前三分。
- **校勘**：紙本頁碼、頁圖與異文比對要接上。
- **更多注家**：慧淨、窺基、宗密、子璿、川禪師等。

## 你可以怎麼參與

- **提供判斷**：哪條解釋該歸給誰、哪兩段文字有承襲關係——這些要具名的人下判斷，機器只提線索。
- **核對原文**：手邊有紙本或藏經影像，可以幫忙把節錄核成定本。
- **貢獻版本**：你熟悉的注家、譯本、校勘記，都可以變成可引用的資料。

四項保證：**永久署名**、**已發布版本凍結**、**未發布可撤回**、**貢獻可以帶走**。
