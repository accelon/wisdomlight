# 金剛經 2016 資料集

> 李慧萍 2016 年論文（五章＋八附錄）的 **193 個注釋節點**與 **151 題問答**，
> 整理成本專案的 `anchor／span／question／answer` 格式。
> 李慧萍是 [github.com/accelon/wisdomlight](https://github.com/accelon/wisdomlight) 的管理員之一，
> 已同意把這批節點與問答放入本 repo。

這是目前 repo 裡最完整的資料集；[`samples/jingang/`](../jingang/README.md) 是較早的格式樣本
（前三分、13 條意見、八人反查），用來驗證 schema。兩者可以並存。

## 一、內容與數量

| 檔案 | 內容 | 數量 |
|---|---|---|
| `anchors.tsv` | 節點樹：經文 3、江味農 11、結構 29、意義單位 193，加 2 個 root | 238 |
| `labels.tsv` | 三套科判名稱：昭明 3、江味農 11、李慧萍 233 | 247 |
| `anchor_map.tsv` | S／E 字碼與文字：經文 3＋11、注釋 193 | 207 |
| `edges.tsv` | 注釋段 → 經文段（`annotates`） | 11 |
| `questions.jsonl` | 151 題 | 151 |
| `answers.tsv` | 問題 → 節點（`answered_by`） | 278 |
| `checks.tsv` | E 文字長度與 E 範圍的核對 | 193 |
| `works.tsv` | 版本（JJN.2011、JJN.B23） | 2 |

節點數的關係：

```
jjn 樹：11（江味農段）＋ 29（結構）＋ 193（意義單位）＝ 233
加經文：vcpp 3 段
加 root：jjn、vcpp
總計：238 個 anchor
```

論文所稱「193 個科判節點」是**最末端的意義單位**；29 個結構節點與 11 個江味農段是上層。
不要把它們混成同一個數字。

## 二、節點樹

```
jjn                        江味農《金剛般若波羅蜜經講義》
├─ jjn/1 … jjn/11          江味農的 11 個科判節點（有 S、E 範圍）
│  ├─ jjn/1-1 …            李慧萍的意義單位（有 E 範圍）
│  ├─ jjn/1-6              結構節點（無自己的 span）
│  │  ├─ jjn/1-6-1 …       意義單位（有 E 範圍）
│  │  └─ …
│  └─ …
vcpp                       金剛般若波羅蜜經（羅什譯；2011 版文字）
├─ vcpp/1                  法會因由分第一（S1-86）
├─ vcpp/2                  善現起請分第二（S87-273）
└─ vcpp/3                  大乘正宗分第三（S274-412）
```

- id 一次發出就不再改；號碼沿用論文的科判編號（`1-6-1` 之類）。
- `jjn/1`、`jjn/2` 都 `annotates` `vcpp/1`；同一段經文可以有多個江味農節點。
- 結構節點沒有自己的 span；查範圍時由子節點取 min/max。

## 三、S／E 字碼

- 座標系是 **2011 版**（江味農《金剛般若波羅蜜經講義》，佛陀教育基金會），
  經文頁 11–13、注釋頁 128–194。
- `S1–S412`：經文 331 字，含標點 412 字。
- 論文原注釋編號是 `E1–E27902`；本資料集依**轉錄文字**重算為 `E1–E27904`
  （逐節見 `checks.tsv` 的 `thesis_start/end` 與 `start/end`）。
- 193 個意義單位的 E 範圍 **連續覆蓋 1–27904，沒有缺口**；11 個江味農段的 S 範圍連續覆蓋 1–412。
- 這些字碼綁 2011 版，不是永久 ID；換版本要另建 `span_map`（B23／T8.235／YLZ）。

### 文字與範圍的 10 個差異

183 個節點的論文 E 字數與文字長度相符；10 個節點不符（差 1–71 字）。
為了讓「範圍 = 文字」一致，E 範圍已依文字重算，`checks.tsv` 同時保留：
`thesis_start/thesis_end`（論文原號）、`start/end`（本資料集）、`status`（`ok`／`adjusted`）。

`ok` 只表示該節點的文字長度與論文 E 字數相符；因為前面的節點可能位移，
`start/end` 仍可能與 `thesis_start/end` 不同。以文字為準；論文原 E 號只用於對照。

## 四、151 題問答

`questions.jsonl` 每行一題：

```json
{
  "schema": "question/0.1",
  "id": "q-0006",
  "text": "如是我聞的意義為何？",
  "asked_by": "person:lee-huiping",
  "scope_anchor": "jjn/1",
  "order_in_section": 6,
  "status": "draft",
  "license": "CC-BY-SA-4.0",
  "source": "李慧萍 2016 論文附錄七",
  "date": "2026-10-21"
}
```

`answers.tsv` 每行一個答案連結：

```
# id	question	anchor	order	evidence	note
a-0006	q-0006	jjn/1-3	1	E287-436	如是與信成就
a-0007	q-0006	jjn/1-4	2	E437-514	我聞與聞成就
a-0008	q-0006	jjn/1-8-1	3	E1814-1891	如是
a-0009	q-0006	jjn/1-8-2	4	E1892-1964	我聞
```

- 151 題、278 個答案；平均 1.84 個答案，最多 13 個。
- 一題多答案時，順序沿用論文；`order` 是答案順序，不是年代。
- 有些答案指向江味農段（例如 `jjn/4`）而不是意義單位；`evidence` 用該段的 E 範圍。
- `status: draft`：資料自論文匯入，尚未逐條核對原書。

## 五、三套科判

`labels.tsv` 用 `vocabulary` 分開三套名稱：

| vocabulary | 掛在哪裡 | 數量 |
|---|---|---|
| `zhaoming` | `vcpp/1`–`3` | 3 |
| `jiang-weinong` | `jjn/1`–`11` | 11 |
| `lee-huiping` | `jjn/1`–`11` 與全部下層節點 | 233 |

同一段經文因此有三個名稱：昭明「法會因由分第一」、江味農「（丙）初證信序」、
李慧萍「1 證信序」。三個名稱各有作者與授權，所以 label 不放在 `anchors.tsv` 裡壓成一個欄位。

- 論文 docx 沒有放入本 repo；本目錄只放整理後的節點、範圍、問答與 E 段文字。
- 引用時請保留：李慧萍（節點、問題）、江味農（注釋）、2011 版（文字）。

## 七、怎麼來的

`tools/build_jingang_2016.py` 讀論文附錄 docx，產生這個目錄：

```bash
python tools/build_jingang_2016.py \
  --appendix "論文附錄(李慧萍0824版).docx" \
  --write
```

附錄 docx 不在 repo，需自備。驗證：

```bash
python tools/check_jingang_2016.py
```

驗證會檢查：id 唯一、parent／label／span／answer 都存在、E 與 S 覆蓋無缺口、
151 題每題至少一個答案、各段題數符合論文（12/41/9/2/8/3/5/3/11/33/24）。

## 九、範例查詢

> 打開 `jjn/1`（江味農的證信序），問「這一支有幾個意義單位？」
> → `jjn/1` → `part_of*` → 23 個葉節點。

> 打開 `vcpp/1`（法會因由分），問「誰注釋過它？」
> → `vcpp/1` ← `annotates` ← `jjn/1`、`jjn/2`。

> 打開 `q-0006`（如是我聞的意義為何？），問「答案在哪？」
> → 4 個 `answered_by` → `jjn/1-3`、`jjn/1-4`、`jjn/1-8-1`、`jjn/1-8-2`。
