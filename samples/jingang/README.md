## 三個經文發現（都是格式問題，不是資料問題）

### 1. 不能靠「行號相等」對齊

笈多本開卷多一句禮敬文：

```
YLZ.238（笈多）  3: 歸命一切佛菩薩海等
                4: 如是我聞：
```

其餘五本第 3 行就是「如是我聞」。所以笈多本的行號整體後移一行，三分起點變成 3/15/31，
其他本是 2/14/30。**行號相近 ≠ 同一句**；對齊只能靠 anchor，不能靠行號。

### 2. 科判本身是主張，不是經文結構

留支本第 21 行有「住分第三」，而昭明第三分（大乘正宗）要到第 31 行的「佛告須菩提」才開始——
同一部經、同一份並行文本裡，兩套分科的分界差了十行。留支本第 2 行還同時有〔序分第一〕與 `^ck1`。

### 3. 證據常常跨行

「一時」在一行、「婆伽婆」在下一行（留支 4–5）；「一時」與「世尊」也分屬兩行（笈多 5–6）。
所以 span 必須是**行範圍**，不能假設一條證據只佔一行。

## 集注：從朱棣剝離六家，再反鏈回原文

《金剛經集注》的體例是「經文一句，接著一串注家」，每位注家前面有**【名】**
（王日休、李文會、肇法師、六祖、僧若訥…）。那個【名】就是現成的作者標記：

| 【名】 | 變成的 claim | 掛在 |
|---|---|---|
| 【王日休曰】 | `c-vj-0008`（如是我聞＝阿難親聞於佛） | `vcpp/1` |
| 【李文會曰】 | `c-vj-0009`（阿難問、佛答「初安如是我聞」） | `vcpp/1` |
| 【肇法師曰】 | `c-vj-0011`（一時＝說此般若時） | `vcpp/1` |
| 【六祖曰】 | `c-vj-0012`（舍衛國＝波斯匿王所居） | `vcpp/1` |
| 【僧若訥曰】 | `c-vj-0013`（次第乞＝不越貧從富） | `vcpp/1` |

**二層引文**也剝得出來：李文會文中說「是故傅大士云」，後面那首偈是傅大士的，不是李文會的。
所以 `c-vj-0010`（傅大士偈）獨立成條，`e-vj-0009` 記「李文會引用傅大士」——
證據範圍是李文會那段文字裡的一段子字串。這是「從注疏中剝離前人、又不把人家的話算在自己頭上」的最小例子。

**反鏈回去**：打開經文第一句，`vcpp/1` 的逆鏈現在是

```
吉藏（隋）· 江味農（民國）· 王日休（宋）· 李文會（明）· 傅大士（梁）
肇法師（晉）· 六祖（唐）· 僧若訥（宋）· 我
```

八位作者、十條 claim、跨一千五百年，全部指回同一段「如是我聞」。這就是集注的資料形狀：
**不是把六家抄在一起，而是同一 anchor 上有六條可署名、可回溯的邊。**

## 對格式的六個要求

1. **span 要帶座標系**：`space = line | char | pcl`。經文用行號，節錄用字元。
2. **科判標籤是註記，不是內文**：`〔護念付囑分第二〕` 清理後沒有字串可引，
   所以「某版本有某分科」的證據只能是**註記 id**（`kind: annotation`）。
3. **anchor 與 label 分離**：`vcpp/2` 是 anchor；「善現啟請」是羅什系 label；
   「住分第三」是留支系 label。同一 anchor 可以有多個 label。
4. **節錄也是 edition**，但要標 `extent` 與 `basis`；不然就是把片段當全書。
5. **前人 claim 也要有 status**：未核原書只能 `draft`，不能因為「這是古書」就預設可信。
6. **引文照錄原貌**：集注是簡體，`quote` 就存簡體，`proposition` 用自己的話（繁體）；
   顯示層要轉再轉，資料層不改寫。
